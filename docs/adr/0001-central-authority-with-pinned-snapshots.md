# 以集中權威與鎖定快照治理跨專案規範

兩端各自維護規範容易漂移，但直接追蹤共用最新版會讓未評估的要求自動生效。因此共通與技術規範集中在獨立儲存庫，以整庫單一版本發布；兩端各自鎖定版本及 Profile，保留完整不可直接修改的本地快照、來源提交與雜湊，而可執行品質工具留原專案。

相較只留連結或以 submodule 追蹤分支，此方式增加更新副本的成本，但保有離線可讀性、版本可重現性與獨立升版。離線檢查不驗證來源真實性，首次匯入與升版必須另外核對來源；初期不新增 CI／hook 門禁。

此決策核准治理方向，不代表目前草案已發布或兩端已正式採用。
